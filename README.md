# Data Warehouse & Analytics Project

## Welcome to the *Data Warehouse & Analytics Project* repository! :)

This project is the result of **The Complete SQL Bootcamp (30 hours)** in which I learn about SQL from zero to hero. In this Git, I present a comprehensive data warehouse and analytics solution, from building a modern data warehouse with SQL Server to generating actionable insights, including ETL processes, data modeling, and analytics. Designed as a portfolio project highlights industry best practices in data engineering and analytics.
